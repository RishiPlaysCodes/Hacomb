# KSP Crime Analytics Dashboard

A Streamlit application for analyzing and visualizing crime data.

## Features
- CSV file upload
- Interactive data table
- Filter by crime type
- Bar chart visualization of crimes by district

## How to Run
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the application:
   ```bash
   streamlit run app.py
   ```

## Sample Data
A sample CSV file `crime_data.csv` is provided for testing the dashboard.
